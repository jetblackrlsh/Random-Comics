Generate all exact readable text directly inside clean rectangular caption boxes in the art. Keep every full caption border and every letter inside a generous outer safe margin. Include only the intended story sentences—never page numbers, panel numbers, caption numbers, labels, prompt scaffolding, duplicated same-page captions, speech bubbles, thought bubbles, floating dialogue, subtitles, watermarks, logos, or extra unreadable text.
