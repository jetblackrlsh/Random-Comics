# Page Script

All pages are full realistic candid photo-comic pages in 4:5 portrait aspect ratio. Caption-box text must be generated directly inside the page art. Use caption boxes only, no speech bubbles, no thought bubbles, no floating subtitles, no blank text boxes, and no later text overlay. Caption boxes must not be numbered or labeled. Story pages should use around five or six panels minimum so the action is easy to follow.
