# Key Item Descriptions

## Key Item: Super Scope Device

- First appears: Issue #1, "The Chest Run"
- Visual identifiers: Compact two-handed high-tech projector shaped like a short tactical telescope; matte gunmetal shell; cyan illuminated lens rings; small foldout transparent display; vented side rails; no brand name or readable markings.
- Continuity notes: Houses an AI scanner and can project heat, anti-gravity, and sleep rays. It provides tactical information but does not make SuperScope invulnerable.
- Reference image: `../reference-images/super-scope-device-key-item.jpg`

## Key Item: Mysterious Chest

- First appears: Issue #1, "The Chest Run"
- Visual identifiers: Large rectangular chest roughly three feet long; unusually heavy; dark unidentified metal alloy; shallow geometric seams; subtle violet crystalline inclusions within the metal; thick side handles; no readable markings; sealed without a visible lock.
- Continuity notes: Contains one object about the size of a football behind a dense energy field that blocks scanning. OSJ connects it to an old case and places it in containment.
- Reference image: `../reference-images/mysterious-chest-key-item.jpg`

## Key Item: OSJ Encrypted Liaison Badge

- First appears: Issue #1, "The Chest Run"
- Visual identifiers: Compact silver badge-device with beveled edges, a vertical blue light at its center, a subtle silver-and-blue shield motif, and no readable text.
- Continuity notes: Grants limited encrypted access to an assigned Officers of Superhuman Justice case coordinator. Pulsewing and SuperScope each receive one after surrendering the chest.
- Reference image: `../reference-images/osj-liaison-badge-key-item.jpg`
