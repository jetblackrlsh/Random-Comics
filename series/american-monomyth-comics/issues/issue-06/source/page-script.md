# Page Script

## Global Image Prompt Contract

Every prompt must ask for a full colorful anime-inspired superhero comic page, 4:5 portrait aspect ratio, high-saturation, high-detail, sharp crisp line art, bright glow effects, modern anime-inspired American superhero comic aesthetic. All readable story text must be generated directly inside caption boxes in the page art. Blank text boxes are not acceptable. Do not add later text overlays. Speech bubbles, dialogue balloons, thought bubbles, manga bubble tails, and floating dialogue text are not allowed. Avoid watermarks, fake publisher logos, real-world company logos, and real-world political symbols.

Keep visible text reader-facing only. Use clean rectangular caption boxes integrated into the art, placed away from faces and key action. Because this issue must be very easy to understand, every page should make the action, motivation, cause-and-effect, and result visually obvious.
