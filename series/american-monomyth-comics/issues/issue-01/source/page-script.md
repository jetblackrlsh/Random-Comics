# Page Script

## Global Image Prompt Contract

Every prompt must ask for a full colorful anime-inspired superhero comic page, 4:5 portrait aspect ratio, high-saturation, high-detail, sharp crisp line art, bright glow effects, modern anime-inspired American superhero comic aesthetic. All readable story text must be generated directly inside the page art. Do not add later text overlays. Avoid blank text boxes, watermarks, fake publisher logos, real-world political logos, or real foreign national symbols.

Keep text short and reader-facing. Use clean caption boxes, poster lettering, emergency screens, or signs only when specified.
