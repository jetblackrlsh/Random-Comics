# Key Item Descriptions

## Key Item: Prism Plate

- First appears: Issue #1, "Armor Against the Eye"
- Visual identifiers: Angular rainbow-silver armor plate sized for Armor On's chest, glasslike layered metal, bright internal glow, prism facets, luminous blue attachment seams when bonded to Armor On's existing armor.
- Continuity notes: Armor On wins the Prism Plate from the Mirror Champion after learning to use astral perception instead of raw armor absorption. It becomes a visible new layer over their silver chest plate by the end of Issue #1.
- Reference image: `../reference-images/prism-plate-key-item.png`

## Key Item: Armor On's Incomplete Armor Set

- First appears: Issue #1, "Armor Against the Eye"
- Visual identifiers: Modular silver armor over a glowing blue-energy body, initially only a chest plate with partial shoulder and forearm hints, later gaining the Prism Plate as a rainbow-silver overlay.
- Continuity notes: Armor On believes completing this armor set will make them invincible enough to survive the hidden watcher. Each new armor piece should feel like both a trophy and a shield against fear.
- Reference image: `../reference-images/armor-on-character.png`
