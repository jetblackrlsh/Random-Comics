# Page Script

Every page is a full realistic candid photo-comic page in 4:5 portrait aspect ratio. All readable title and story text must be generated directly inside clean parchment-colored rectangular caption boxes in the page art. Use caption boxes only; no speech bubbles, thought bubbles, floating subtitles, blank text boxes, later text overlay, page numbers, panel numbers, caption numbers, caption labels, or duplicated caption wording on the same page.
